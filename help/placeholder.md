# KubesTUI

This KubesTUI was built without homelabCD's README, so its help is empty.

## Getting the help

homelabCD copies its README into KubesTUI (help/homelabcd.md) when it builds
it. Builds from homelabCD have it:

- On a node: **Update homelabCD and KubesTUI**
- On this computer: **Update KubesTUI on This Computer**

To build it yourself, copy homelabCD's README.md to help/homelabcd.md in
the KubesTUI folder before `go build`.
